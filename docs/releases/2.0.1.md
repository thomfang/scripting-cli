# scripting-cli 2.0.1

## New and Enhanced Features

- Updated the bundled development guide for screenshot and widget-preview requests in the background with a compatible App version. Results reflect actual rendering, capture errors or timeouts.
- 更新随包开发指南，说明支持此功能的 App 版本可在后台接收截图和小组件预览请求，结果以实际渲染、截图错误或超时为准。

## Improvements and Fixes

- Improved `scripts create/attach` guidance: compatible App versions can bind in the background and show the current debug page when returning to the foreground.
- Fixed foreground-only instructions while retaining guidance for errors returned by older App versions.
- 改进 `scripts create/attach` 指引：支持此功能的 App 版本可在后台绑定，回到前台时再展示当前调试页。
- 修复仅允许前台操作的指南内容，同时保留旧版 App 返回错误时的处理说明。
