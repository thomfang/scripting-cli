# scripting-cli 2.0.2

## New and Enhanced Features

- Added support for copying bundled documentation, examples and assets from a compatible Scripting App to `docs/Scripting Documentation/` in the current workspace.
- Added `--screenshot-final` to capture the latest script view when a script exits, with a compatible Scripting App.
- 新增从支持此功能的 Scripting App 将内置文档、示例和资源复制到当前工作区的 `docs/Scripting Documentation/`。
- 新增 `--screenshot-final`，配合支持此功能的 Scripting App，在脚本退出时截取最后呈现的视图。

## Improvements and Fixes

- Improved desktop Skill listings with display titles and descriptions to make skills easier to find.
- Improved documentation updates to preserve the previous complete copy when synchronization fails and leave other workspace documents untouched.
- 改进桌面端 Skill 列表，提供显示标题和描述，方便查找技能。
- 改进文档更新，同步失败时保留上一份完整副本，不影响工作区中的其他文档。
