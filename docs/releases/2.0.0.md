# scripting-cli 2.0.0

## New and Enhanced Features

- Added development of a selected Skill in `skills/<name>`, with file synchronization to the App. Use an App version that supports Skill mode.
- Added `skills run <name> <entry>` to test `.ts` and `.tsx` entries, return logs and results, check code with `--check`, and stream progress with `--stream`.
- Updated script management to `scripts list`, `scripts inspect`, `scripts create`, and `scripts attach`. **Breaking change:** JSON consumers must rename `project`, `projects`, and `currentProject` to `script`, `scripts`, and `currentScript`, update `project_*` errors to `script_*`, and use `selecting_script` / `script_attached`. The old `projects` command remains a hidden compatibility alias. See the latest [usage documentation](https://github.com/thomfang/scripting-cli#usage) for current commands.

- 新增选定 Skill 的开发支持，在 `skills/<name>` 中编辑文件并同步到 App。需使用支持 Skill 模式的 App 版本。
- 新增 `skills run <name> <entry>`，可测试 `.ts`、`.tsx` 入口并返回日志和结果，支持 `--check` 检查代码、`--stream` 流式查看进度。
- 更新脚本管理命令为 `scripts list`、`scripts inspect`、`scripts create`、`scripts attach`。**不兼容变更：**解析 JSON 的工具需将 `project`、`projects`、`currentProject` 改为 `script`、`scripts`、`currentScript`，将 `project_*` 错误码改为 `script_*`，并使用 `selecting_script` / `script_attached`。旧 `projects` 命令保留为隐藏兼容别名。当前命令用法请参阅最新[使用文档](https://github.com/thomfang/scripting-cli/blob/master/README_zh.md)。

## Improvements and Fixes

- Improved Skill synchronization to preserve App metadata and other Skills, report conflicting edits, and apply files saved during a test after the test ends without running again automatically.
- Fixed cancellation before execution so a canceled test cannot start running code afterward.

- 改进 Skill 同步，保留 App 元数据及其他 Skills，提示修改冲突；测试期间保存的文件会在测试结束后同步，不会自动再次运行。
- 修复执行前取消测试后，代码仍可能开始运行的问题。
